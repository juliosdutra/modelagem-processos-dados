# Projeto Final – PPEQ-1040

Nesta pasta serão disponibilizados materiais relacionados ao **projeto final da disciplina**.

## Orientações
- O projeto pode ser individual ou em grupo.
- Deve envolver **dados reais ou sintéticos**, aplicando as técnicas vistas em aula.
- A entrega consiste em:
  - Relatório técnico (PDF)
  - Notebook com a implementação (Python)
  - Apresentação (slides)

## Sugestões de temas
- Modelagem baseada em dados para predição de variáveis de processo
- Desenvolvimento de sensores virtuais
- Identificação de parâmetros em processos químicos
- Modelagem híbrida (fenomenológica + dados)

> O projeto final vale **25% da nota total** da disciplina.
