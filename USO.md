## 📂 Como acessar o material
- Todo o conteúdo está organizado nas pastas:
  - `aulas/` → slides e notas
  - `exercicios/` → listas e resoluções
  - `notebooks/` → exemplos em Python (executáveis no Google Colab)
  - `projeto/` → orientações do projeto final

## ▶️ Executando os notebooks
1. Clique no badge **Abrir no Colab** no README principal.
2. Escolha o notebook desejado na pasta `notebooks/`.
3. Clique em **Run All** para executar todos os blocos de código.
